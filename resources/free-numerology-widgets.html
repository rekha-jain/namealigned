How to add a widget

  • WordPress: add a Custom HTML block and paste the code.
  • Blogger, Wix, Squarespace, Ghost: use the HTML or embed block.
  • Several widgets on one page: paste each div; the script line is needed only once.

Frequently asked questions

Are the numerology widgets really free?

Yes. They are free to use on any site, including commercial blogs. We only ask that you keep the small credit link.

Do the widgets collect my readers' data?

No. All calculations happen in the reader's browser. Nothing they type is sent to NameAligned or stored.

Will a widget slow my page down?

The script is small and loads asynchronously, so it does not block your page from rendering.

Which numerology system do the widgets use?

Chaldean numerology, the sound-based system. Name numbers use Chaldean letter values; birthday and personal year numbers use date digits.
