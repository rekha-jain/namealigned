The Chaldean letter values

In Chaldean numerology, letters are assigned by sound vibration rather than simple alphabetical order. The number 9 is usually kept apart as a sacred or completion number, so no English letters are assigned directly to 9 in the core chart.

1A, I, J, Q, Y
2B, K, R
3C, G, L, S
4D, M, T
5E, H, N, X
6U, V, W
7O, Z
8F, P
9No direct letter assignment

How to calculate a name number

  1. Write the daily-use name, the version people actually call you.
  2. Convert each letter to its Chaldean value using the chart.
  3. Add the values to get the compound number.
  4. Reduce the compound number to a single digit, unless you are interpreting the compound separately.

Example: Priya

P = 8, R = 2, I = 1, Y = 1, A = 1. The compound total is 13. Reduce 13 as 1 + 3 = 4. So the reduced name number is 4, with a compound-number layer of 13.
