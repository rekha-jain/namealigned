# Traffic plan for namealigned.com

Baseline: ~150 users/month across 149 indexable pages, average position ~31.5.

## What the audit ruled out

**Internal linking is not the bottleneck.** Nearly every page already receives
147+ internal inbound links from global nav and footer. There is no orphan
problem left and no meaningful equity to redistribute. Adding more internal
links would do nothing.

**Page count is not the bottleneck.** 149 pages earning 150 users is ~1 user per
page per month. The site does not need more pages of the kind it already has;
45 compatibility pages already average 401-455 words.

**The real constraint is authority.** Position 31.5 means page 3-4 of results.
Content quality does not move that; external links and brand signals do.

## The strategic opening

The site already speaks Moolank/Bhagyank and targets an Indian audience. The
highest-volume Indian numerology queries it does **not** cover are tools, not
articles. Tools also attract links, which is the actual constraint. That makes
tool-building the one activity that fixes traffic and authority at the same time.

Coverage probe across the whole site:

| Topic | Mentions | Dedicated page | India demand |
|---|---|---|---|
| Lo Shu Grid | 202 | blog post only, no tool | high |
| Mobile number numerology | 25 | none | high |
| Marriage matching by DOB | 0 | none | very high |
| House / flat number | 1 | none | high |
| Vehicle number | 0 | none | medium |
| Master numbers 11/22/33 | 0 | none | high |
| Angel numbers | 0 | none | very high, but off-system |

**Lo Shu Grid is the standout.** Highest demand of the on-brand gaps, the site
already has 202 mentions and a written guide, and a grid calculator is a
naturally linkable asset. It is the cheapest bridge from existing expertise to a
query people actually type.

**Angel numbers is deliberately excluded.** ~450k monthly searches, but it is a
different system from Chaldean. Publishing it would contradict the methodology
page and dilute topical focus in a YMYL-adjacent niche. Not worth the trust cost.

## Phases

### Phase 1 — on-site hygiene (fast, no content risk)
- `/ask-aura`: 88 visible words, `index, follow`, in sitemap, 129 internal
  inbound links. The thinnest page on the site is absorbing the most link equity
  and looks like a doorway page. Give it real content or de-index it.
- 21 meta descriptions run 160-231 chars and truncate in results.
- Thin compatibility pages (401-455 words) need depth, not more siblings.

### Phase 2 — tools that earn links
1. Lo Shu Grid calculator
2. Mobile number numerology checker
3. Marriage / compatibility matching by date of birth
4. House number numerology

### Phase 3 — fill the doctrinal gap
Master numbers 11, 22, 33. Three pages, high demand, and their absence is
currently a visible hole in a site that claims completeness.

### Phase 4 — authority and distribution
The actual constraint. Pinterest and Instagram carry numerology audiences and
rank in Google; outreach and citations build the link profile. No amount of
on-site work substitutes for this.

## Sequencing note

Phases 1 and 3 are safe. Phase 2 is where the traffic is. Phase 4 is where the
ranking is. Doing 1-3 without 4 will raise impressions and leave position flat.
